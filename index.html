What are MCP servers?

The Model Context Protocol (MCP) is an open standard that lets AI assistants connect to outside tools and data through one common interface. An MCP server is a small program that exposes a specific resource — a dataset, an API, a document collection — so that any MCP-compatible assistant can discover and use it without a custom, one-off integration. In practice that means an assistant can pull a live forecast, search a catalog, or run an analysis by calling a server, rather than someone wiring each system together by hand. This registry maps where NOAA and its partners are building and experimenting with those servers. Learn more about MCP →
